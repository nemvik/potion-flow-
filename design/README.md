# Sem patří export z Claude Design

Ulož hlavní soubor jako `design.html`. Není součástí tohoto zadání a musí vzniknout v designovém kroku.

Jestliže export používá další soubory, zachovej je zde a opravuj jen nezbytné relativní cesty. Soubor musí být možné otevřít/prohlédnout jako vizuální referenci. Codex má jeho podobu přenést do skutečných herních komponent; nemá přepsat původní návrh ani jej vložit přes iframe.
